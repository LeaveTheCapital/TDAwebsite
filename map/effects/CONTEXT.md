# Change impact

Use this index to select cards, then follow their first-order **Hits** and source citations. Outside consumers of absolute paths require a separate owner check.

| Changing | Open first |
|---|---|
| HTML entry points, CSS, or build inputs | [Pages](../objects/pages/_index.md), [page build](../processes/page-build.md) |
| Song sections or lyric cues | [Songs](../objects/performance/songs.md), [transport](../processes/live-performance.md) |
| Setlist order or live-set MIDI notes | [Setlist](../objects/performance/setlist.md), [transport](../processes/live-performance.md) |
| MIDI clock, drum notes, or drum drawing | [Drum state](../objects/performance/drum-state.md), [transport](../processes/live-performance.md) |
| Letter contours or lyric animation | [Animated text](../objects/performance/animated-text.md), [font guide](../../font.md) |
| Audio visualizer or captions | [Audio and captions](../objects/performance/audio-captions.md) |
| Dice roll or die drawing | [Dice](../objects/performance/dice.md) |
| MIDI config or upload | [MIDI editor](../objects/editors/midi-config.md), [storage](../objects/editors/storage-port.md), [persistence](../processes/editor-persistence.md) |
| Books, films, series, or games | [Media library](../objects/editors/media-library.md), [storage](../objects/editors/storage-port.md), [persistence](../processes/editor-persistence.md) |

## Check

Before an edit, the editor verifies the selected card’s citations at the current revision and checks any relevant external path consumers with the owner.
